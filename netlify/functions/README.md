# Netlify Functions

API traffic is proxied via `dist/_redirects` (generated by `build.py`), not serverless functions.

Set `API_URL` in Netlify environment variables, e.g.:

```
API_URL=https://civiclens-api.onrender.com
```

The FastAPI backend must be hosted on Render/Railway/Fly.io — see `NETLIFY.md`.
